# log

`log TEXT`, save TEXT into output report.

> Example files in `examples/301-log`.

## Example

* Logging ERROR, WARN and INFO messages.

```ruby
group "Learning about log messages" do
  log "Using log messages."

  target "Create user david"
  run "id david"
  log result.value
  expect "david"

  log "Problem detected!", :error
  log "This is a warning", :warn
  log "Hi, there!", :info
end
```

* Logging an Array config param, and a Hash config param:

```yaml
---
global:
  values1:
  - A1
  - B1
  - C1
  values2:
    p1: A2
    p2: B2
    p3: C2
cases:
- tt_members: TOCHANGE
```

```ruby
group "Log: Array, Hash" do
  log "-------------"
  log "Array values : #{get(:values1)}"
  log "Hash values  : #{get(:values2)}"
end
```
